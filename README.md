# 舞迹 / Dance Trace

单机位短舞段的本地动作观察 Demo。原视频和估计三维姿态共用视频时间轴，支持慢放、A–B 循环、多角度查看、手腕与脚踝轨迹、肩胯辅助线及同步镜像。

## 运行

要求 Python 3.10+、支持 WebGL 的现代桌面浏览器。推荐先用 10–20 秒的单人全身、固定机位、光线清晰视频。

```bash
python3 scripts/download_assets.py
python3 -m http.server 8765 --bind 127.0.0.1
```

打开 http://127.0.0.1:8765 ，选择 ≤90 秒视频，点击「分析动作」。模型和依赖首次下载需要联网，此后可断网运行。视频使用浏览器本地对象 URL，不发送给服务器，也不会提交到 GitHub。MOV 能否播放取决于视频编码；无法解码时请先转换成 H.264 MP4。

## 实际能力和边界

- 使用 MediaPipe Pose Landmarker full 模型输出 33 个身体关键点，约每秒采样 20 帧。GPU 初始化失败时尝试 CPU。处理耗时取决于设备与视频，未承诺实时速度。
- 三维姿态属于单目估计；旋转后的画面不是实际多机位拍摄。遮挡、快速转身、深度与肩胯的细微扭转可能估计错误。
- 三维展示以骨盆为中心，保留朝向，但**不恢复舞者在地面的全局移动轨迹**。三维手脚轨迹是相对身体的路线；原视频叠加轨迹保留画面内的位置变化。
- 缺失姿态不回填；被遮挡、出画、明显位置突变会标记在时间轴上。提示只反映检测到的异常，不代表未标记的姿态一定正确。轨迹和平滑会在异常处断开。
- 半透明人形由关节与几何体构成，用于动作观察，不是精确人体表面重建。第一版不提供手指细节、自动教学拆步、动作打分、多人跟踪、自动剪辑和云处理。

## 开发与测试

不需要打包器或 npm install。网页采用 ES modules；请使用 HTTP 服务，不能直接双击 HTML。

```bash
node --test tests/*.test.js
```

`src/core.js` 管理时间采样、异常检测和平滑；`src/app.js` 管理视频分析及同步交互；`src/renderer.js` 管理三维显示。原始检测帧和显示帧分别保留在运行时，刷新页面即释放，不保存视频或姿态数据。

`vendor/` 由下载脚本生成且不进版本库。依赖锁定为 Three.js 0.180.0（MIT）和 MediaPipe Tasks Vision 0.10.14（Apache-2.0）。下载脚本校验 npm 包的发布 SHA-1。模型使用 Google 官方 pose_landmarker_full/float16/1 文件。仓库源代码采用 MIT 许可，依赖及模型的条款按各自官方说明执行。

## 迭代方向

1. 用真实舞段记录遮挡、转身和快速动作的失败情况，验证学习效果。
2. 优化长片段处理、模型下载诊断与异常呈现。
3. 评估更完整的三维恢复方法与全局位移，接入前明确算力需求和实际准确性。

初版重点是可运行与可验证；尚未证明它能够准确还原任意舞蹈。
